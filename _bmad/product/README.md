# Product/UX Phase Artifacts

> **Вход:** Discovery-артефакт (`_bmad/discovery/{task-id}.md`)
> **Агенты:** analyst → ux-designer
> **Следующая фаза:** Architecture

## Структура артефакта

Каждый артефакт сохраняется как `_bmad/product/{task-id}.md`.

Полный шаблон: `docs/agents/agent-output-contracts.md#product`

```markdown
# Product: {Название продукта/фичи}

## Target Audience
- {сегмент}: {роль, цели, боли}

## Value Proposition
{ценностное предложение}

## User Stories
- {FR-1}: {описание}

## Non-Functional Requirements
- {NFR-1}: {описание}

## UX Decisions
- {решение}: {обоснование}

## Success Metrics
- North Star: {метрика}
```
