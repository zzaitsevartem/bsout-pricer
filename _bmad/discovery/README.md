# Discovery Phase Artifacts

> **Вход:** бизнес-гипотеза / задача / проблемное описание от пользователя
> **Агент:** analyst
> **Следующая фаза:** Product/UX

## Структура артефакта

Каждый артефакт сохраняется как `_bmad/discovery/{task-id}.md`.

Полный шаблон: `docs/agents/agent-output-contracts.md#discovery`

```markdown
# Discovery: {Название задачи}

## Problem Statement
{core problem statement}

## Stakeholders
- {имя / роль}: {интересы}

## Boundaries
- Входит: {scope}
- Не входит: {out-of-scope}

## Success Criteria
- [ ] {критерий}

## Constraints
{ограничения}
```
