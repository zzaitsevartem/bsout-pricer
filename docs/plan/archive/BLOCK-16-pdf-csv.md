## БЛОК 16 — Экспорт отчётов (PDF/CSV) для тарифа Продвинутый

**Статус:** [x] 2026-07-27 · **P1**

**Итог.** Последняя проданная, но не существовавшая функция тарифной сетки закрыта. **Решение владельца: оба формата.** Проверено живыми запросами: CSV 21,5 КБ (BOM для Excel, разделитель `;`, десятичная запятая, 128 строк) и PDF 52,7 КБ — **отрисовку PDF смотрел глазами**, отрендерив его в картинку.

**Проблема (найдено при визуальной проверке `/tariffs` 2026-07-25).** Страница тарифов честно рендерит матрицу из `plans.py` и показывает «Экспорт отчётов (PDF/CSV) ✓» для Продвинутого. Но экспорта **не существует**: `grep` по `backend/src/modules/` находит слово только во флаге `export_reports` в `plans.py` и в схемах платежей — ни эндпоинта, ни сервиса, ни генератора файлов. Ни один блок плана его не создавал. То есть за 499 ₽ продаётся функция, которой нет в коде — ровно та проблема, которую закрывали Блоки 12 и 13, просто в последнем оставшемся углу тарифной сетки.

- [x] Выбран **reportlab** (чистый Python; weasyprint потребовал бы системных cairo и pango в контейнере). Установлен, внесён в `requirements.txt` и `pyproject.toml` — заодно синхронизировал их, они разошлись и не содержали ни arq, ни парсерных зависимостей.
- [x] `GET /api/export/catalog.csv` и `.pdf` с теми же фильтрами, что у каталога. **UTF-8 с BOM и разделитель `;`** — иначе Excel на Windows покажет кракозябры и склеит числа в одну колонку. **Экранирование CSV-инъекций**: значение, начинающееся с `=`, Excel исполнил бы как формулу на машине клиента; числа при этом намеренно не экранируются, иначе отчёт перестал бы считаться.
- [x] `GET /api/export/tracking.csv` — текущая и целевая цена, дельта, число магазинов.
- [x] **Первое боевое применение `require_feature`** — функция была написана в Блоке 12 и не использовалась нигде. Проверено вживую: на триале 403 `feature_unavailable` с `requiredPlans: ['advanced']`.
- [x] Стриминг пакетами (буфер каждые 200 строк, выборка по 500) — каталог не собирается в память. Лимит 10 000 строк для CSV и 2 000 для PDF; при превышении **413 с фактическим числом строк**, а не молча урезанный файл, который приняли бы за полный отчёт (проверено: лимит 50 при 128 строках → 413).
- [x] Кнопка выгрузки в поиске с передачей текущих фильтров; для тарифов без экспорта — призыв перейти на Продвинутый вместо ошибки. Сборка, линт и tsc чисты.

### 🐞 Найдено визуальной проверкой (тесты этого не видят)

Первый собранный PDF выглядел корректно, но в заголовках вместо знака `₽` стоял **пустой квадрат**: символ рубля добавлен в Unicode в 2014 году, и в шрифте его не оказалось. Тесты такое не ловят — они проверяют, что PDF валиден, а не что он читаем. Добавлена проверка покрытия глифов с подстановкой (`₽` → `руб.`), после чего отрисовка проверена повторно.

⚠️ **Отдельно про шрифты:** шрифты из поставки reportlab (Bitstream Vera) **кириллицу не содержат вообще** — без внешнего TTF все русские названия стали бы прямоугольниками. В образ добавлен пакет `fonts-dejavu-core`, в коде — цепочка поиска шрифта (переменная окружения → пути Linux → пути macOS) и честный 503 с объяснением, если шрифт не найден.
