## Поверхности BScout, требующие ручной проверки

### Frontend-интеграция (Блок 01) — требует `npm install` + запущенный бэк на :8000
- ⬜ `npm install && npm run build && npm run lint` из `frontend/` проходят без ошибок (в сессии не запускались — нет `node_modules`).
- ⬜ Логин: неверные креды → сообщение «Неверный email или пароль»; верные → редирект на `/account`, Header показывает Кабинет/Выйти.
- ⬜ Регистрация: валидация (пароль ≥6, совпадение паролей, согласие) → успех логинит и редиректит на `/account`.
- ⬜ Guard: аноним на `/account`, `/subscription`, `/admin` → редирект на `/login`. Не-админ на `/admin` → редирект на `/account`.
- ⬜ Кабинет: профиль/подписка/история подтягиваются из API; при отсутствии подписки — «нет активной подписки»; `settings` сохраняет профиль (`PATCH /users/me`).
- ⬜ Подписка: смена тарифа (`POST /payment/subscribe`) и отмена (`POST /payment/cancel`) отражаются в UI после инвалидации.
- ⬜ Выход (`useLogout`) чистит localStorage и возвращает Header в состояние Войти/Регистрация; кросс-таб `storage`-sync работает.

### Docker / порты (Блок 04) — требует сети
- ⬜ `docker build ./backend` проходит; `docker compose up -d` поднимает pg+redis+backend, миграции применяются на старте контейнера.
- ⬜ Локально сервисы слушают порты из `bsout-pricer/.env` (backend **8010**, pg 5434); без `.env` (прод) — 8000/5432/6379. Ничего не конфликтует с чужими проектами.
- ⬜ Фронт (`npm run dev`) через `BACKEND_URL=http://localhost:8010` реально ходит в свой бэкенд (а не в чужой сервис на 8000).
- ⬜ Прогон всех эндпоинтов в контейнере (curl/httpx).

### Парсеры
- ⬜ Реальный скрейп каждого магазина не падает на текущем HTML (структура сайтов меняется без предупреждения).
- ⬜ Нормализация имён (`Product.normalized_name`) корректно группирует одинаковые позиции разных магазинов.

### Платежи и подписки
- ⬜ «Показанная цена == списанная сумма» на реальном платёжном флоу.
- ⬜ Идемпотентность платежа: повторный webhook не создаёт второе списание / вторую подписку.
- ⬜ Гейтинг платных фич по тарифу (`trial` / `basic` / `advanced`) реально блокирует доступ (middleware `subscription_guard`).

### Кэш и данные
- ⬜ Redis-кэш поиска не отдаёт устаревшую цену после обновления парсером.
- ⬜ `RateLimitMiddleware` (120 req / 60s) не режет легитимный трафик и корректно ограничивает превышение.
