## Исправления

- Общий search_predicate сохраняет точные/частичные совпадения и добавляет для Advanced PostgreSQL strict_word_similarity по отдельным словам, вместо обязательного сравнения короткого запроса со всем длинным названием. Nokia больше не исчезает из офферного поиска Advanced; основной канонический каталог тоже использует тарифный fuzzy.
- Добавлены ограниченные группы синонимов/вариантов: дисплей/экран/display/lcd, iphone/айфон, samsung/самсунг, galaxy/галакси, nokia/нокиа, аккумулятор/батарея/battery. Поддерживаются обе клавиатурные раскладки. Опечатки длинных алиасов исправляются существующим edit_distance(limit=1), включая перестановки; специальное hardcode-правило для dsiplay не требуется.
- Цифровые и модельные токены не проходят fuzzy-подмену. Проверены iPhone13 против12 и A53 противA52. Это ограниченный словарь, не универсальная многоязычная NLP/транслитерация любого произвольного слова.
- GET /api/products/catalog/suggestions стоит до динамического product_id. Типизированный ответ [{id,canonical_name}], q2–500 символов, limit1–8 (UI6), активная подписка обязательна. Запрос выбирает только id/name через EXISTS активного оффера активного магазина; все магазин/цена/наличие условия проверяются на одном оффере, учтены dictionary filters. Нет агрегирования всех офферов/count_total ради подсказок. Точные prefix/partial варианты приоритетнее fuzzy.
- UI: локальный ввод сохранён, suggestions debounce200ms, запрос только при фокусе и >=2 символах, AbortSignal и query key с фильтрами. До6 реальных названий, мышь/ArrowUp/ArrowDown/Enter/Escape, blur скрывает список, выбор применяет запрос без дублирования через350ms.
- На полном обновлении обнаружена hydration-ошибка из-за того, что auth-store успевал стать готовым до гидратации Suspense: серверный loading shell не совпадал с клиентским каталогом. SearchClient теперь использует useSyncExternalStore с устойчивым serverSnapshot для фазы гидратации. Добавлен renderToString/hydrateRoot regression. После исправления при live reload новых hydration ошибок в browser log не появилось; старые записи13:18 оставались в сохранённом журнале.
