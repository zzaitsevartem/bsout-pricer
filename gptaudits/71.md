# Гостевая главная — редизайн, 2026-11-11

Ветка: `bscout/redesign-2026-11-11`.

- Пересобрана только публичная главная: поиск, сравнение без вымышленных цен, преимущества, шаги, тарифы, CTA и гостевой футер. Авторизованная главная по-прежнему выбирает `AuthorizedHome`.
- Гостевой поиск на главной (hero, header, подсказки и CTA) ведёт в `/register`; вне этого сценария прежняя маршрутизация поиска сохранена. Текст запроса не переносится: регистрация не поддерживает безопасное восстановление запроса.
- Домашние тарифы используют `usePlans` и `planFeatures`, без годового переключателя и захардкоженных цен. Общие тарифные компоненты не изменены.
- Маскот использует прозрачные позы из пакета, неподвижный слой корпуса и маску слоя головы. Указатель работает только на видимом маскоте при fine pointer без reduced motion; моргание и слушатели очищаются при уходе/скрытии. Эталонный спрайт с белым фоном не использован.
- Секции имеют якоря и `min-height: 100svh`; desktop snap proximity, на узких/touch/reduced-motion выключен. Гостевой футер ссылается только на существующие страницы и настроенные email-адреса.

Проверки: 49 focused Vitest (включая прежние shared search тесты), `npm run lint`, `npx tsc --noEmit`, `npm run build`, `git diff --check` — успешно. Luna прочитала исходники и дважды пересмотрела тесты Terra; после последнего замечания Terra добавила проверку неподвижности корпуса.

Браузер: локальная production-сборка открыта в IAB при ширине около 875 px; проверены hero, навигация и тарифные карточки. Отдельный desktop/mobile viewport и вход в авторизованный аккаунт в браузере не проверены: браузер не дал сменить viewport, Chrome на компьютере был заблокирован. Разделение auth/guest подтверждено кодом и тестами, не визуальной сессией.
