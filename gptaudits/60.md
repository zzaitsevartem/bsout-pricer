# Сессия 60 — stale backend скрыл источник карточки (2026-11-06)

Пользователь сообщил, что реальные карточки показывают «Источник недоступен». Код выборки источника уже был: активные привязанные офферы фильтруются теми же магазинными, retail price и stock условиями, затем выбирается минимальная розничная цена с ID оффера как tie-break. API выдаёт offer/store ID, имя/slug и URL; карточка показывает ссылку на источник либо fallback.

Причина: работающий `bscout-backend` был здоровым, но устаревшим image, созданным 2026-11-05, без bind mounts. Внутри runtime `CatalogItemResponse.model_fields` не содержал `source`; SHA исходников не совпадал с workspace. Compose строит backend из `./backend`, Dockerfile копирует `src` в image. Старый response model исключал новое поле, а Zod `.default(null)` переводил отсутствие поля в fallback. Fallback скрывал устаревший backend.

Terra пересобрала и пересоздала только backend командой `docker compose up -d --build --no-deps --force-recreate backend`; DB, Redis, worker и миграции не затрагивались. Gate-check перепроверил runtime OpenAPI (`source=True`) и авторизованный GET реальных данных: `Защитная плёнка Apple iPhone 15 (Чёрный)`, retail 7.00, Профи (`profi`), URL `https://siriust.ru/aksessuary/zaschitnye-plenki/plenka-iphone/zaschitnaya-plenka-dlya-iphone-15-6.1-dyuyma-ceramics-hd-chernaya-ramka/`, 1 offer. Source offer/store/URL/price совпали с первым предложением detail response.

Предыдущие regression-проверки Terra на неизменённом коде: backend comparison API 38 passed, frontend card 5/5 passed, TypeScript/lint/Ruff/Python syntax прошли. Это code-test evidence до runtime rebuild, не повторный post-rebuild suite. Runtime/API проверки после rebuild пройдены.

Визуальный скриншот карточки не получен: CUA browser был недоступен, отдельная Chrome-вкладка не создалась, headless путь запрещён активными правилами. API исправление подтверждено; rendered-page визуальная приёмка остаётся ручным follow-up и не помечена как пройденная. `.env` не читали, пользовательскую browser session не трогали, коммитов нет.
