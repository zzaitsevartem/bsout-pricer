## Диагноз и изменения

Terra проверил авторизованный живой интерфейс: обе существовавшие позиции имели нулевую price_delta. Серые бары были следствием выбранной ранее нейтральной обработки нуля, а не отсутствующей CSS-загрузки. При этом заливка снижения исторически была bg-slate. Теперь рост — bg-clay, снижение — bg-olive, ноль — заметный bg-slate; отсутствие данных остаётся светлым. Добавлена короткая легенда. Нулевое изменение не выдаётся за рост или снижение; исходные цены не редактировались.

DeviceTracking теперь содержит карточку слева и текст справа, зеркально TrackingOverview с карточкой справа. Одинаковые визуальные размеры, адаптация для мобильного экрана: заголовок перед карточкой. В обеих сетках процентные ширины заменены долями minmax, чтобы gap не вызывал переполнение; длинные названия устройств переносятся.

Живая ошибка «Не удалось загрузить устройства» вызвана старым запущенным backend: GET /api/tracking/devices попадал в старые маршруты и возвращал 405, таблицы tracked_devices отсутствовали, версия Alembic была 077299b69ec0. Это отличалось от ранее проверенного кода ветки. Миграция применена к локальной БД; backend обновлён.

Luna по прямому запросу пользователя сама нашла и обновила актуальные тарифные поверхности: API PlanResponse/list_plans, frontend payment schema, общие TariffPlans/tooltip (используются в guest home и subscription), таблицу /tariffs, FAQ, Advantages, DESIGN, subscriptions, technical-specification и bussines-plan. Пункт «Отслеживание новых запчастей устройств» доступен только Advanced; API явно возвращает соответствующий bool. Исторические аудиты/архивы не переписывались. Terra добавил проверки контракта и отображения. Root проверил diff и распределение ответственности; чужие untracked аудиты 73/75 сохранены.
