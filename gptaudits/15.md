Дата: 2026-10-27.

Пользователь попросил добавить навык и агента для изображений, затем уточнил: не разрабатывать собственные инструкции, искать готовое популярное решение через Луну. До уточнения новых профилей не создавалось.

## Выбор и происхождение

Луна (bscout_reader) сравнила официальный openai/skills imagegen, JimLiu/baoyu-skills, inference-sh/skills и msitarzewski/agency-agents. Выбрана связка уже установленного официального imagegen для рендеринга с готовым Image Prompt Engineer для арт-дирекшна/промптов. Большое число GitHub stars относится ко всему agency-agents, а не отдельному агенту; независимые отзывы/рейтинг конкретного агента не подтверждены. Абсолютное первенство по популярности не установлено.

Источник: https://github.com/msitarzewski/agency-agents
Версия: b37b5bb33b78f2c1d6567d98e25ca818e3259219.
Профиль: design/design-image-prompt-engineer.md.

Во временной sparse-копии /private/tmp/bscout-image-agent.jASL9F/upstream просмотрены профиль и официальный scripts/convert.sh с lib.sh. Официальным конвертером созданы форматы codex и antigravity (стандартный SKILL.md). В проект скопированы только выбранные навык/агент и лицензии MIT:

- .agents/skills/agency-image-prompt-engineer/SKILL.md
- .agents/skills/agency-image-prompt-engineer/LICENSE.txt
- .codex/agents/image-prompt-engineer.toml
- .codex/agents/image-prompt-engineer.LICENSE.txt

Методика не переписана, инструкции агента совпадают с телом upstream Markdown. Модель не зафиксирована: upstream профиль наследует настройки хоста. Глобальные настройки, defaults моделей, приложение и зависимости не менялись. Агент занимается промптами; для фактической генерации основной агент использует установленный imagegen. Команды пользователя вроде «поручи художнику ...» являются маршрутизацией через основного агента.

Загрузка новой именованной роли текущим хостом и реальная генерация через неё не тестировались; статическая установка не доказывает активацию.
