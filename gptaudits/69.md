Дата: 2026-11-09
Ветка: `bscout/animations`

## Объём и исходное состояние

- Источник задачи — `animate.md`; решения по конкретным эффектам согласованы с Astra.
- Добавлен общий переход содержимого страницы; общие Header/Footer остаются вне анимируемого блока.
- Затронуты главная, поиск, страницы устройства и товара, кабинет и его разделы, админка, тарифы и подписка, авторизация, контакты, FAQ и юридические страницы.
- `/product` перенаправляет на `/search`. `not-found`, `error` и `global-error` показывают восстановление сразу, без зависимости от анимации.
- Чужие удаления `.claude/*` и пользовательские untracked `animate.md`, `.agents/skills/animate/`, `skills-lock.json` не входят в scoped commit.

## Текущие изменения

- `PageTransition` использует короткий WAAPI fade для основного содержимого и отменяет движение при reduced motion, смене видимости документа или навигации.
- Мобильное меню, tariff/registration tooltip и логотипная карусель получили ограниченные переходы и состояния reduced motion.
- Карусель запускается только в видимой вкладке и области, останавливается при фокусе/наведении/явной паузе; статичное состояние показывает только доступные исходные ссылки.
- Regression tests добавлены для `PageTransition`, карусели и Header.

## Проверки

- G1 Vitest: final gate reverify завершился с exit 0; новый запуск включал обновлённый Header regression.
- G2 lint: final gate reverify завершился с exit 0, без ESLint предупреждений и ошибок.
- G3 изолированный production build: автоматическая проверка завершилась с exit 0; лог содержит `Route (app)` и 25 static pages.
- G4 browser: В отдельном IAB при 390×844 drawer открывался/закрывался за 220/160 мс; Enter несколько раз переключал его без горизонтального overflow, body scroll lock очищался после закрытия. Быстрые SPA переходы FAQ → Contacts → Privacy и Back/Forward отображали заголовок текущего маршрута, content layer оставался один. Гостевой поиск `iphone 13` по Enter перешёл на `/search?q=iphone+13`, визуально сохранил запрос и фокус. На `/devices/samsung-s20` состояние «Загрузка устройства…» сменилось заголовком «Запчасти и аксессуары для Samsung Galaxy S20». Tooltip виден при keyboard focus. При паузе/focus карусели движение останавливалось, копии ссылок скрывались; четыре исходные ссылки оставались видимыми в Tab order. Screenshot меню: [mobile-menu.jpg](assets/animations-2026-11-09/mobile-menu.jpg). Нативный Chrome использовался только для reduced-motion emulation: кнопка паузы исчезла, четыре доступные ссылки оставались в accessibility tree. Не проверяли reduced-motion page fade отдельным browser reload; его bypass покрывает unit-тест. Живые authenticated страницы не проверяли.
- Compiled CSS после финального specificity fix проверен в отдельном browser origin: при `top=825px` и viewport `720px` карусель имела `data-running=false`/`play-state: paused`; при `top=105px` — `true`/`running`; снова вне экрана (`top=-1335px`) — `false`/`paused`.
- G5 controlled loading: изолированный Next + loopback proxy на выделенных портах. Device и планы вернули fixture data; delayed catalog success вернул 200 через 8003 мс: skeleton сменился данными. Simulated backend-down вернул 502 за 8 мс, затем последовали штатные retries около +1/+3/+7 с и inline error с Retry. Delayed-error вернул четыре 503 примерно через 5 с каждый, после retries показал inline `Fixture error` с Retry. Существующие пользовательские listeners `localhost:3000` (PID 3665) и `localhost:8000` (Docker PID 1222) не меняли и не останавливали. Отдельный price-history request залогирован с wall time 904292 мс; причина неизвестна.
- G6 финальная проверка diff: новых `transition-all`/`transition: all`, движения для поиска/фильтров/цен/таблиц и новых animation dependencies нет; каждый новый эффект имеет reduced-motion путь. `git diff --check` чисто.

## UX-ориентиры и ограничения наблюдений

- Официальный [Vercel Web Interface Guidelines](https://vercel.com/design/guidelines) прочитан как guidance: reduced-motion вариант, преимущество CSS и transform/opacity, interruptible motion, ограничение долгих autoplay-петель, отказ от `transition: all`; guidelines также предлагают задержку показа skeleton/spinner около 150–300 мс и минимум показа около 300–500 мс.
- На [Linear](https://linear.app/) через отдельный временный browser tab наблюдался только загруженный статичный hero, навигация и демонстрационный интерфейс. Motion не наблюдался и не заявляется как проверенный пример.
- Схемы фронтенда сверены с фикстурами disposable QA proxy для device, каталогов, деталей товара, истории цен и тарифов.

## Итог

Кодовые и browser/API проверки G1–G6 пройдены. Ручные сценарии использовали отдельный тестовый frontend и proxy; production services не затрагивали. Состояние commit/push фиксируется в локальном ledger и финальном отчёте.
